# Educational Tutorials

Standalone tutorials, organized by subject rather than by course. Each tutorial is a folder with the page, its figures, and working code in MATLAB, Python, R, and Mathematica.

## Differential Equations

- [Solving IVPs Numerically](Differential%20Equations/IVP%20Mass-Spring/): solve and plot any mass-spring initial value problem with a built-in adaptive solver, check whether the answer can be trusted, and see what the solver does under the hood.
